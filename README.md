## التقنيات المستخدمة

- **React + Vite**: لبناء واجهة سريعة وسلسة.
- **Tailwind CSS**: لتنسيق التصميم بسرعة واحترافية.
- **React Router**: للتنقل بين صفحات الموقع.
- كل بيانات المتجر (المنتجات، الإعدادات، التصنيفات) موجودة في ملفات منفصلة داخل مجلد
  `src/data/` بحيث تعدّلها دون الحاجة لفهم الكود.

## 1) كيفية تشغيل المشروع

بعد تثبيت المتطلبات (الخطوة التالية)، افتح الطرفية (Terminal / cmd) داخل مجلد المشروع `app`
واكتب:

```
npm run dev
```

سيظهر لك رابط مثل `http://localhost:5173` — افتحه في المتصفح لترى الموقع يعمل على جهازك.
أي تعديل تحفظه في الملفات سيظهر تلقائيًا في المتصفح دون الحاجة لإعادة التشغيل.

لإيقاف التشغيل، اضغط `Ctrl + C` داخل الطرفية.

---

## 2) كيفية تثبيت المتطلبات

### أ) تثبيت Node.js

المشروع يحتاج برنامج **Node.js** (نسخة 20 أو أحدث). حمّله من الموقع الرسمي:
https://nodejs.org (اختر النسخة LTS) وثبّته كأي برنامج عادي.

للتأكد من نجاح التثبيت، افتح الطرفية واكتب:

```
node -v
npm -v
```

يجب أن يظهر لك رقم إصدار لكل منهما.

### ب) تثبيت مكتبات المشروع

من داخل مجلد `app` (المجلد الذي يحتوي على ملف `package.json`)، شغّل الأمر التالي **مرة واحدة**
فقط بعد فك ضغط المشروع أو عند نقله لجهاز جديد:

```
npm install
```

سيقوم هذا الأمر بتحميل كل المكتبات اللازمة تلقائيًا داخل مجلد `node_modules`.

> ملاحظة: مجلد `node_modules` غير مرفق داخل الملف المضغوط لتقليل الحجم، لذلك يجب تشغيل
> `npm install` أولًا قبل `npm run dev` أو أي أمر آخر.

## 3) كيفية تغيير اسم المتجر

افتح الملف: `src/data/settings.js`

عدّل القيم التالية:

```js
storeName: "STORE_NAME",       // اسم المتجر بالعربية
storeNameEn: "STORE_NAME_EN",  // اسم المتجر بالإنجليزية (اختياري)
tagline: "...",                // الشعار التسويقي القصير
shortDescription: "...",       // وصف مختصر يظهر في الفوتر وصفحة من نحن
```

هذا الملف هو المصدر الوحيد لاسم المتجر، وسيظهر تلقائيًا في كل الصفحات (الهيدر، الفوتر،
عنوان المتصفح، صفحة من نحن...).

كذلك عدّل عنوان الصفحة الافتراضي وعلامة SEO داخل نفس الملف:

```js
seo: {
  defaultTitle: "STORE_NAME | عطور فاخرة وأصلية",
  defaultDescription: "...",
  siteUrl: "https://SITE_DOMAIN.com", // ضع نطاقك الحقيقي هنا بعد النشر
  ogImage: "/assets/images/banners/og-cover.svg",
},
```

> لا تنسَ أيضًا تحديث عنوان الصفحة في ملف `index.html` (الموجود في جذر المشروع) في وسم
> `<title>`، لأنه يظهر قبل تحميل الموقع بالكامل.

## 4) كيفية تغيير الشعار

الشعارات موجودة داخل: `public/assets/images/branding/`

- `logo.svg` — الشعار الأساسي (يظهر في الهيدر على خلفية فاتحة)
- `logo-light.svg` — نسخة فاتحة من الشعار (تظهر في الفوتر على خلفية داكنة)
- `favicon.svg` — أيقونة المتصفح الصغيرة

**الطريقة الأسهل**: صمّم شعارك بأي برنامج تصميم (Canva مثلًا) واحفظه بنفس الأسماء أعلاه
وبنفس الامتداد (svg أو png)، ثم استبدل الملفات القديمة بالجديدة داخل نفس المجلد.

> إذا استخدمت صيغة PNG بدلًا من SVG، افتح ملف `src/data/settings.js` وغيّر الامتداد في
> الأسطر التالية من `.svg` إلى `.png`:
> ```js
> logo: "/assets/images/branding/logo.svg",
> logoLight: "/assets/images/branding/logo-light.svg",
> favicon: "/assets/images/branding/favicon.svg",
> ```
> ولا تنسَ تحديث رابط الأيقونة في ملف `index.html` أيضًا (وسم `<link rel="icon" ...>`).

## 5) كيفية إضافة منتج

افتح الملف: `src/data/products.js`

في نهاية القائمة (قبل السطر `];` الأخير)، أضف منتجًا جديدًا بنفس الشكل التالي، واحرص على
وضع فاصلة `,` بعد المنتج الذي قبله:

```js
{
  id: "P-1013",                    // رقم فريد لم يُستخدم من قبل
  name: "اسم العطر الجديد",
  brand: "اسم العلامة التجارية",
  category: "oud",                 // يجب أن يطابق أحد التصنيفات في categories.js
  gender: "رجالي",                 // "رجالي" | "نسائي" | "للجنسين"
  perfumeType: "او دو بارفان",
  shortDescription: "وصف قصير يظهر في بطاقة المنتج",
  fullDescription: "وصف كامل تفصيلي يظهر في صفحة المنتج",
  price: 299,
  oldPrice: 349,                   // ضع null إن لم يكن هناك خصم
  mainImage: "/assets/images/products/my-new-product-main.svg",
  images: ["/assets/images/products/my-new-product-alt-1.svg"],
  size: "100 مل",
  availableSizes: ["50 مل", "100 مل"],
  notes: {
    top: ["مكوّن 1", "مكوّن 2"],
    middle: ["مكوّن 3"],
    base: ["مكوّن 4"],
  },
  rating: 4.5,
  reviewsCount: 0,
  inStock: true,
  isNew: true,
  isBestSeller: false,
  isFeatured: false,
  relatedProducts: ["P-1001"],     // معرّفات منتجات أخرى مرتبطة (اختياري)
},
```

بعد الحفظ، سيظهر المنتج تلقائيًا في صفحة "جميع المنتجات"، والبحث، والتصفية، وأي قسم في
الرئيسية يطابق شروطه (مثل `isNew` أو `isFeatured`).

> **بخصوص الصور**: ضع صورك الحقيقية داخل `public/assets/images/products/` بنفس الأسماء
> التي كتبتها في `mainImage` و `images`. راجع قسم "كيفية تغيير الصور" أدناه لمزيد من التفاصيل.

## 6) كيفية حذف منتج

في نفس الملف `src/data/products.js`، ابحث عن المنتج المطلوب حذفه عبر اسمه أو رقم `id`
الخاص به، ثم احذف الكتلة كاملة الخاصة به من القوس `{` إلى القوس `}` متضمنة الفاصلة التي
تليها.

> نصيحة: إذا كان منتج آخر يشير إلى هذا المنتج داخل `relatedProducts`، يفضّل حذف تلك
> الإشارة أيضًا حتى لا يظهر رابط لمنتج غير موجود.

## 7) كيفية تعديل الأسعار

في `src/data/products.js`، ابحث عن المنتج المطلوب وعدّل القيمتين التاليتين مباشرة:

```js
price: 299,      // السعر الحالي (السعر الذي يدفعه العميل فعليًا)
oldPrice: 349,   // السعر قبل الخصم — ضع null إن لم يكن هناك خصم
```

نسبة الخصم المعروضة على بطاقة المنتج (مثل "خصم 15٪") تُحسب تلقائيًا من الفرق بين
`price` و `oldPrice`، فلا داعي لحسابها يدويًا.

## 8) كيفية تغيير الصور

جميع صور الموقع موجودة داخل: `public/assets/images/` مقسّمة إلى:

```
public/assets/images/
├── products/    → صور المنتجات (رئيسية وإضافية)
├── categories/  → صور التصنيفات
├── banners/     → صور البانرات (الهيرو، العروض، صورة المشاركة على السوشيال ميديا)
└── branding/    → الشعار وأيقونة المتصفح
```

**لاستبدال صورة حقيقية بدلًا من الصورة التجريبية:**

1. جهّز صورتك بصيغة `jpg` أو `png` أو `webp` (يُفضّل أبعاد متقاربة للصور من نفس النوع،
   مثلًا كل صور المنتجات بنسبة عرض إلى ارتفاع 4:5).
2. ضع الصورة داخل المجلد المناسب (مثلًا `products/` لصور المنتجات).
3. افتح `src/data/products.js` (أو `categories.js` حسب الحالة) وغيّر مسار الصورة ليشير
   إلى اسم ملفك الجديد، مثال:

```js
mainImage: "/assets/images/products/oud-al-amir-real-photo.jpg",
```

> جميع الصور الحالية هي صور بديلة (Placeholder) تم توليدها تلقائيًا لتوضيح شكل الموقع فقط،
> ويُفضّل استبدالها جميعًا بصور حقيقية لمنتجاتك قبل إطلاق الموقع للجمهور.

## 9) كيفية تعديل بيانات التواصل

كل بيانات التواصل والشبكات الاجتماعية موجودة في ملف واحد: `src/data/settings.js`

```js
phoneNumber: "PHONE_NUMBER",          // مثال: +966500000000
whatsappNumber: "WHATSAPP_NUMBER",    // بدون + وبدون مسافات، مثال: 966500000000
email: "STORE_EMAIL@example.com",
address: "STORE_ADDRESS",
workingHours: "WORKING_HOURS",

social: {
  instagram: "INSTAGRAM_URL",
  tiktok: "TIKTOK_URL",
  snapchat: "SNAPCHAT_URL",
  facebook: "FACEBOOK_URL",
  twitter: "TWITTER_URL",
},
```

استبدل كل قيمة برابطك أو رقمك الحقيقي، واحفظ الملف — ستتحدث كل الصفحات (الهيدر، الفوتر،
صفحة تواصل معنا، قسم إنستغرام في الرئيسية) تلقائيًا.

## 10) كيفية تعديل الألوان

نظام الألوان معرّف في مكان واحد: `src/index.css` داخل قسم `@theme` في أعلى الملف:

```css
@theme {
  --color-ink: #14120f;        /* اللون الأساسي الداكن (أسود دافئ) */
  --color-ivory: #faf6ef;      /* خلفية الموقع (أبيض عاجي) */
  --color-ivory-deep: #f2ead9; /* خلفية أغمق قليلًا للأقسام المتناوبة */
  --color-gold: #b08d57;       /* اللون الذهبي الأساسي */
  --color-gold-deep: #8a6b3b;  /* ذهبي أغمق (يُستخدم في الأزرار والروابط) */
  --color-gold-light: #d9c39b; /* ذهبي فاتح (يُستخدم عند التحويم Hover) */
  --color-line: #e2d8c2;       /* لون الخطوط والحدود الفاصلة */
  --color-charcoal: #4a463d;   /* لون النصوص الثانوية */
  --color-burgundy: #5c2323;   /* لون تنبيهات الخصم */
  --color-success: #3f6b4a;    /* لون حالة "متوفر" */
}
```

غيّر أي قيمة لون (بصيغة hex مثل `#b08d57`) لتغيير المظهر في كامل الموقع فورًا، لأن كل
مكوّنات الموقع تستخدم هذه المتغيرات نفسها (لا توجد ألوان مكتوبة يدويًا في مكان آخر).

## 11) كيفية تعديل النصوص

- **نصوص الصفحة الرئيسية** (العنوان الرئيسي، الأقسام، لماذا نحن): داخل `src/pages/Home.jsx`
  والمكوّن `src/components/Hero.jsx`.
- **نصوص من نحن**: داخل `src/pages/About.jsx`.
- **الأسئلة الشائعة**: داخل `src/pages/FAQ.jsx` في مصفوفة `faqs`.
- **السياسات** (الخصوصية، الشروط، الاستبدال والاسترجاع): داخل `src/pages/Privacy.jsx`،
  `src/pages/Terms.jsx`، `src/pages/ReturnPolicy.jsx` — كل سياسة مقسّمة إلى أقسام
  بعنوان `heading` ونص `body`، عدّل النصوص مباشرة داخل هذه الملفات.
- **آراء العملاء**: داخل `src/data/reviews.js`.

كل النصوص مكتوبة بشكل مباشر بين علامتي اقتباس `" "`، يمكنك تغييرها دون التأثير على باقي
الكود طالما حافظت على علامات الاقتباس والفواصل كما هي.

## 12) كيفية بناء الموقع للنشر (Production Build)

عندما تنتهي من كل التعديلات وتكون جاهزًا للنشر، شغّل من داخل مجلد `app`:

```
npm run build
```

سينشئ هذا الأمر مجلدًا باسم `dist/` يحتوي على النسخة النهائية المضغوطة والسريعة من موقعك،
الجاهزة للرفع على أي استضافة. يمكنك أيضًا معاينة هذه النسخة النهائية محليًا قبل الرفع عبر:

```
npm run preview
```

## 13) كيفية نشر الموقع على الاستضافة

بعد تنفيذ `npm run build`، لديك مجلد `dist/` يحتوي على كل ما يحتاجه الموقع. اختر إحدى
الطرق التالية:

### الطريقة الأسهل: Netlify أو Vercel (مجانية وسريعة)

1. أنشئ حسابًا مجانيًا على netlify.com أو vercel.com.
2. اسحب مجلد `dist` وأفلته مباشرة في لوحة تحكم Netlify (خيار "Deploy manually" أو
   "Drag and drop")، أو اربط المشروع بحساب GitHub لنشر تلقائي عند كل تعديل مستقبلي.
3. الموقع يعمل مباشرة بروابط نظيفة تلقائيًا (تم تجهيز ملف `_redirects` و `vercel.json`
   مسبقًا داخل المشروع لهذا الغرض بالضبط).

### استضافة مشتركة تقليدية (cPanel وما شابه)

1. بعد `npm run build`، ادخل إلى مجلد `dist`.
2. ارفع **كل محتويات** مجلد `dist` (وليس المجلد نفسه) إلى مجلد `public_html` في استضافتك
   عبر FTP أو مدير الملفات.
3. ملف `.htaccess` مرفق مسبقًا داخل `dist` (تم إعداده ضمن `public/.htaccess`) يضمن عمل
   روابط الصفحات الداخلية بشكل صحيح دون ظهور خطأ 404 عند تحديث الصفحة.

### بعد النشر

- افتح `src/data/settings.js` وحدّث `seo.siteUrl` برابط نطاقك الحقيقي.
- افتح `public/sitemap.xml` و `public/robots.txt` واستبدل `SITE_DOMAIN.com` بنطاقك الحقيقي.
- أعد تنفيذ `npm run build` ثم أعد رفع الموقع لتحديث هذه الروابط.

## أسئلة شائعة تقنية

**س: عدّلت ملفًا ولم يظهر التغيير؟**
تأكد أنك تشغّل `npm run dev` وتنظر إلى الرابط الذي ظهر في الطرفية، وتأكد من حفظ الملف
(Ctrl + S) بعد التعديل.

**س: ظهرت رسالة خطأ عند تشغيل `npm run dev`؟**
تأكد أنك نفّذت `npm install` أولًا داخل نفس مجلد `app`، وأن نسخة Node.js لديك 20 أو أحدث
(`node -v`).

**س: كيف أضيف طريقة دفع جديدة؟**
افتح `src/data/settings.js` وأضف عنصرًا جديدًا داخل مصفوفة `paymentMethods` بنفس شكل
العناصر الموجودة، مع `enabled: true` لتفعيلها. لتفعيل الدفع الإلكتروني الحقيقي، ستحتاج
لاحقًا لربط بوابة دفع (مثل PayTabs أو Moyasar أو Stripe) بواسطة مطوّر، والبنية جاهزة
لاستقبال ذلك عبر صفحة `src/pages/Checkout.jsx`.

**س: هل يمكن ربط الموقع بقاعدة بيانات حقيقية بدلًا من ملفات `data/`؟**
نعم، البنية الحالية مصممة بحيث تكون البيانات منفصلة تمامًا عن الواجهة، مما يسهّل على أي
مطوّر مستقبلًا استبدال هذه الملفات بطلبات API متصلة بقاعدة بيانات دون إعادة بناء الواجهة.
